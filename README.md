# projeto lobo - clone de interface

este projeto é uma reprodução de um layout do figma, com foco em prática de html e css e fidelidade ao design original.

## objetivo

praticar construção de interfaces a partir de protótipos, trabalhando com:
- estruturação em html
- estilização em css
- organização de layout
- fidelidade ao figma
